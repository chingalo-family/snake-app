# Snake App — App Icon Concept & Inspirations

## Goal

A store-ready icon that reads as **Snake App** at 48×48 and looks premium at 1024×1024. Instant recognition: snake + playful energy, not a generic gamepad or emoji dump.

---

## Concept directions (pick one primary)

### Concept A — “Coil & Jewel” (recommended)

- Stylized snake coiled into a soft **S** (for Snake)
- Head at top-right with a friendly eye
- Small amber “food jewel” near the mouth (score/reward cue)
- Background: deep forest green radial → `#0B1F1A` to `#14825C`
- Flat vector, 2–3 colors max inside the glyph

**Why it works:** letterform recognition + brand greens + amber reward accent.

### Concept B — “Pixel Revival”

- Soft-rounded pixel snake (4–6 segments) on a rounded square
- One fruit/animal pixel morsel
- Nostalgic arcade feel without harsh 8-bit edges

**Why it works:** genre-true; risks looking like many other snake clones—differentiate with our green/amber palette.

### Concept C — “Leaf Serpent”

- Snake silhouette integrated with a leaf/vine curve
- Nature-first Chingalo Family vibe
- Slightly more “wellness / outdoor” than arcade

**Why it works:** unique brand story; slightly less “game” at a glance—use stronger eye/food accent if chosen.

---

## Visual rules

| Do | Don’t |
|----|-------|
| Simple silhouette readable small | Tiny text in the icon |
| 2–3 colors + background | Photoreal snake skins |
| Centered glyph with padding for maskable | Edge-to-edge crowded detail |
| Rounded geometry matching app UI radii | Neon purple glow stacks |
| Friendly, not scary | Fangs / blood / horror |

---

## Inspirations (mood, not copies)

- Classic Nokia snake clarity (legibility first)
- Modern casual game icons (Brawl Stars–level shape clarity, not art style)
- Nature apps’ calm greens (AllTrails / Forest mood) blended with arcade energy
- Animal collectible charm (think recognizable silhouette, like a mascot mark)

Reference keywords for designers: *friendly serpent mascot, rounded S-curve, forest green, amber berry, flat vector, app icon, maskable safe zone*.

---

## Technical deliverables

| Asset | Size | Notes |
|-------|------|-------|
| Master | 1024×1024 PNG | Transparent or full-bleed background |
| Android adaptive | Foreground + background layers | Safe zone 66% diameter |
| iOS | AppIcon set | No alpha on App Store marketing icon |
| Web | 192, 512, maskable | Match PWA theme |
| Desktop | `.ico` / `.icns` | Windows / macOS |

**Safe zone:** keep critical snake + jewel inside ~80% center for circular crop (Android).

---

## Palette for icon

- Background: `#0B1F1A` → `#14825C`
- Snake body: `#3ECF98` / `#1FA87A`
- Eye / highlight: `#F2F7F4`
- Food jewel: `#F0A202`

---

## Naming / store listing cue

Icon should stand alone without the words “Snake App”. The store title carries the name; the mark carries the emotion: **playful, collect, grow**.

---

## Approval checklist

- [ ] Recognizable at notification size
- [ ] Distinct from legacy `snake-app` icon if both remain installed (optional new jewel accent)
- [ ] Matches in-app splash mark
- [ ] Works in light and dark system shelves
- [ ] Maskable Android version tested
