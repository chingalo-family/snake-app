# Full release 1.2 — Sprint

**Intended version:** `1.2.0`  
**Depends on:** current 1.1 campaign (unchanged)  
**Detail:** [plans/01-session-and-objectives.md](../plans/01-session-and-objectives.md) § Sprint  
**Experience gap:** no short, shareable session — [GAME_EXPERIENCE.md](../GAME_EXPERIENCE.md)

## Player experience

Open the app, tap **Challenges → Sprint**, play **60s or 90s** on a seeded board with the **same snake** (swipe / arrows). Beat the clock for a score; crash still ends early. Compare to a personal best for that layout.

Campaign **Play** and all 30 levels behave exactly as in 1.1.

## UX

| Surface | Change |
|---------|--------|
| Home | One secondary **Challenges** control (chip or nav row). **Play** FAB unchanged. Not a grid of modes. |
| Challenges | List of Sprint layouts (3–5). Each card: duration, wall type (Classic or Wrap), seed preview, best. Chip + tip before Start. |
| Playground HUD | Existing score · best · pause, plus **amber countdown**. Last 10s optional SFX if SFX is on. |
| Time up | **Success** sheet (score vs best), not collision thud. Actions: Retry · Quit to Challenges. |
| Crash | Existing game over sheet. |
| Scores | Per-layout Sprint bests in the scores module. Profile still required to persist. |
| Share | Optional: include Sprint score on the existing branded image when score > 0. |

Pause / rotation: **timer pauses** (same soft-pause idea as campaign resize).

## Modes

Reuses **Classic** or **Wrap** only. No Maze in 1.2 unless a layout is explicitly QA’d (prefer open boards).

## Must not change

Play → levels, four campaign mode names, unlocks, combo rules, SFX/BGM split, onboarding (except a one-line Challenges mention only if it does not add a fifth onboarding page).

## Out of scope (1.2)

Zen, Collector, growing walls, Dash, Daily, extra Home tiles.

## Acceptance

1. Player can complete a Sprint from Home without Settings.
2. Time-up and crash are visually distinct.
3. Timer stops while paused and during orientation remapping.
4. Guest can play; save bests needs profile.
5. EN + SW for Challenges, Sprint, timer, success sheet.
6. `flutter analyze` clean; tests for timer expiry, pause, crash.

## Tests to add
