# Full release 1.3 — Zen and Collector

**Intended version:** `1.3.0`  
**Depends on:** 1.2 Challenges IA  
**Detail:** [plans/01-session-and-objectives.md](../plans/01-session-and-objectives.md)  
**Experience gap:** no practice mode; maze has no true “clear”

## Player experience

- **Zen:** play Classic or Wrap until collision. No countdown, no level fail. Optional soft goals (length / score) that do not fail the run.
- **Collector:** eat **N marked** rare/epic collectibles to **win** the run. Collision still fails. Remaining targets always spawnable (never unwinnable).

Campaign level numbers stay 1–30. Unlock-by-score remains the default for most levels.

## UX

| Surface | Change |
|---------|--------|
| Challenges | Add **Zen** and **Collector** entries beside Sprint. Same list/card pattern as 1.2. |
| Zen HUD | Score, length, best — **no timer**. Tip before Start: “No levels — just grow.” |
| Collector HUD | Compact chips, e.g. `Rare 1/3`. Pulse or highlight target icons on the board (Reduce Motion: static highlight). |
| Collector success | Fanfare (SFX on) + success sheet; Retry / Quit to Challenges. |
| Campaign (optional) | At most **2–4 maze levels** gain Collector **in addition to** existing score unlock — listed explicitly in the level catalog, not a silent retcon of 1–12. |

Quit from Zen/Collector uses the same pause verbs as campaign (Resume, Restart, Quit).

## Modes

Zen: Classic or Wrap. Collector: Classic / Wrap / Maze with targets guaranteed a path.

## Must not change

1.2 Sprint; Play FAB; profile gate; swipe/arrows; existing per-level bests.

## Out of scope (1.3)

Peaceful fill-the-board, lives, reverse controls, Key fruit (wait for 1.5 if needed).

## Acceptance

1. Zen never ends on time.
2. Collector completes only when N targets are eaten; non-targets do not complete.
3. Targets cannot be blocked forever by spawn rules.
4. Veterans still see the same campaign numbering.
5. EN + SW; analyze + tests green.

## Tests to add

- Zen: no timer; bests update only with profile.
- Collector: N targets complete; collision fails; non-target eat does not complete.
