# Full release 1.5 — Burrows and bitter fruit

**Intended version:** `1.5.0`  
**Depends on:** Challenges IA; Collector HUD from 1.3 helpful if Key fruit is included  
**Detail:** [plans/02-google-snake-inspired.md](../plans/02-google-snake-inspired.md)  
**Experience gap:** Wrap is the only “teleport”; all food is always safe

## Player experience

- **Burrows:** two matching portal tiles. Enter one, exit the other, **same facing**. Self-collision still kills. **Not** a replacement for Wrap (whole edge still loops only in Wrap).
- **Bitter fruit:** a second wilted collectible. Eating it **does not randomize steering**. Effect: score 0, shrink a few segments, brief slow. Discriminable by **shape/icon**, not color alone.

Optional: **Key fruit** (eat key, then lock becomes edible) only if 1.3 Collector chips already feel natural.

## UX

| Surface | Change |
|---------|--------|
| Challenges / later expert campaign | New chips: **Burrows**, **Bitter fruit** (and Key if shipped). Tip before Start, e.g. “Burrows swap you to the other hole.” |
| Board | Matching amber rings on both burrows; wilted vs ripe art. |
| Audio | Optional soft whoosh on burrow (SFX toggle). Bitter: distinct but not “error spam.” |
| Wrap levels | Unchanged dashed/glow **edge** cue. |

## Modes

Keep `GameMode.wrap` = edge torus. Burrows = paired cells. A later mix (Wrap + Burrows) is **2.0 mix-two**, not 1.5 default.

## Must not change

Swipe mapping; reverse rejection; Wrap semantics on existing wrap levels.

## Out of scope (1.5)

Twin / Yin-Yang, random teleport-on-eat, Sokoban, poison that forces random turns.

## Acceptance

1. A→B and B→A portals; food never on portal cells.
2. Wrap campaign still dies only on self (and obstacles if maze), never on edge.
3. Bitter fruit never uses color as the only difference.
4. EN + SW; tests for portal pair and bitter effect (no direction scramble).

## Tests to add

- Portal exit facing; no skip-through collision exploit on exit tile.
- Bitter: length/slow effect; direction queue still player-controlled.
