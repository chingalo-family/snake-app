# Full release 1.6 — Shield and Dash

**Intended version:** `1.6.0`  
**Depends on:** stable HUD from 1.2–1.3  
**Detail:** [plans/05-power-ups-combos-modifiers.md](../plans/05-power-ups-combos-modifiers.md) · [plans/04-slither-and-io-inspired.md](../plans/04-slither-and-io-inspired.md)  
**Experience gap:** combos already reward routing; no clutch save or burst speed

## Player experience

Combos stay as in 1.1 — **do not** sell them as a new mode.

- **Shield:** rare collectible. Survive **one** self or obstacle hit (visually obvious bark/armor on head or HUD pip). Then shield is gone.
- **Dash:** hold a **large HUD control** (touch, ≥48×48) or Space/Shift (desktop) to move faster for a short time, **spending length** down to a minimum. Swipe/arrows still set direction. **No** virtual joystick.

Guests can use both; persistence of stats still needs a profile.

## UX

| Surface | Change |
|---------|--------|
| HUD | One shield pip; Dash control only while playing (not on Home). Landscape: keep compact, don’t cover the board. |
| Feedback | Power-up glow already listed in UX_DESIGN; honor Reduce Motion. |
| Settings | No new audio toggle. Dash whoosh on SFX channel. |
| Campaign / Challenges | Spawn Shield rarely; Dash available in Sprint/Zen/campaign per catalog flags — **not** all three stacked on every level. |

Pause: Dash does not fire; shield timer (if any) pauses.

## Must not change

Primary movement = swipe / arrows. Reverse-into-self still rejected **including while dashing**.

## Out of scope (1.6)

Online arena, Slow + Dash + Shield on every level, Dash as the only control.

## Acceptance

1. Shield clearly visible when active; one hit consumes it.
2. Dash cannot drop below minimum length; dropped pellets optional and documented.
3. Desktop Space: if Space already pauses, pick **Shift for Dash** or move pause to Esc-only while playground focused — document the choice in UX_DESIGN when implementing.
4. EN + SW; tests for shield consume, dash length floor, reverse rejection while dashing.

## Tests to add

- Dash speed + length; reverse still blocked.
