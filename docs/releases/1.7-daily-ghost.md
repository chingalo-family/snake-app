# Full release 1.7 — Daily seed, ghost, hot-seat

**Intended version:** `1.7.0`  
**Depends on:** 1.2 Sprint (hot-seat); Challenges list  
**Detail:** [plans/06-local-challenge-and-party.md](../plans/06-local-challenge-and-party.md)  
**Experience gap:** nothing “today”; cannot race yesterday’s self; no pass-the-phone

## Player experience

Still **no accounts and no live leaderboard**.

- **Daily grove:** one layout from **device calendar date** + mode. Same day, same seed on that phone. Copy: **this device, today** — never imply worldwide ranks.
- **Ghost:** optional replay of your PB path, **cosmetic** (no collision). Hide or simplify when Reduce Motion is on.
- **Hot-seat Sprint:** two or more **local profiles** take turns on the same Sprint layout; “Hand to the next player” sheet in the current dialog style.

Share image may mention Daily/Sprint when those scores exist — same 1.1 PNG flow.

## UX

| Surface | Change |
|---------|--------|
| Challenges | **Today’s grove** card (date + mode chips). Ghost toggle on suitable modes (Sprint/Zen/campaign optional). |
| Scores | Daily best for today; does not replace campaign bests. |
| Hot-seat | Between runs: hand-off sheet; uses existing profile picker. |
| Settings | Optional “Show ghost” under Display — not a new settings group wall. |

## Must not change

Offline-first; Play → campaign; no network required to finish Daily.

## Out of scope (1.7)

Cloud friends, required share-to-play, timezone-global leaderboards.

## Acceptance

1. Daily seed stable for a given local date; next calendar day rotates.
2. Ghost does not kill the player in v1.
3. Hot-seat never requires the internet.
4. EN + SW including the “this device” honesty line.
5. Analyze + tests for seed stability and ghost playback bounds.
