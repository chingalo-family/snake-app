## Candidate experiences (pick a thin slice)

Ship **one** pillar, not all at once:

| Candidate | Experience | Risk |
|-----------|------------|------|
| **Grove arena** (local bots) | Slither-like, offline | HUD clutter, CPU on mid phones |
| **Lantern** (fog around head) | Tension / memory | Unfair with Maze + rotate |
| **Eat-all maze** | True Nibbler clear | Dense HUD |
| **Mix-two-rules** cards | Novelty with **exactly two** chips | Settings blender UI would break UX |
| **Desktop two-player** vine trail | Party on keyboard | Never dual-swipe on one phone |
| **Shed skin / vine trail** | You paint your own maze | Unfair combos |

A Home **mode hub** (Classic campaign vs Wrap campaign vs …) is a **deliberate** IA change. Only do it if playtests ask; it is not required to enhance the game.
